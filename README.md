# Customer Support Analytics

A portfolio project that simulates customer support ticket data and turns it into actionable service insights.

## Project goal

Build a simple, reproducible analytics workflow using fictional customer support tickets.

The project will:

- Generate realistic fictional support tickets.
- Expose tickets through a local REST API.
- Retrieve and clean data with Python.
- Calculate support KPIs, including response time, resolution time, and SLA breaches.
- Classify contact reasons from ticket text.
- Detect possible repeat contacts.
- Export clean data for a Power BI dashboard.

## Tech stack

- Python
- FastAPI
- requests
- pandas
- scikit-learn
- pytest
- Git and GitHub
- Power BI

## Data privacy

All ticket data in this project is fictional. No real customer data, personal data, credentials, or private API keys will be used or uploaded.
